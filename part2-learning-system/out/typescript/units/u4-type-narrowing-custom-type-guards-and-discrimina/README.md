# Type Narrowing, Custom Type Guards, and Discriminated Unions

## Outcomes

- Narrow union and unknown types using JavaScript runtime operators
- Author user-defined type guard functions with type predicates
- Model API states with discriminated unions and enforce exhaustive compile-time checking

## Project

Build a network state manager and action dispatcher for the web app that processes discriminated union actions, validates raw incoming API messages with custom type guard predicates, and ensures exhaustive action handling at compile time.
