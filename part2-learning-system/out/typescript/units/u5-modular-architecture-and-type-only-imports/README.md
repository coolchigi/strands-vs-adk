# Modular Architecture and Type-Only Imports

## Outcomes

- Structure multi-file TypeScript applications using standard ES Module syntax
- Use type-only imports and inline type specifiers to optimize bundler output and avoid runtime elision issues

## Lessons

- [ES Modules with Types and Values](u5-l1-es-modules-with-types-and-values/README.md)
- [Type-Only Imports and Bundler Optimization](u5-l2-type-only-imports-and-bundler-optimization/README.md)

## Project

Refactor the entire web application project into a modular architecture consisting of separate files for models, type guards, API client utilities, and state reducers, utilizing type-only imports throughout to ensure complete bundler elision and compiling cleanly under strict tsconfig settings.
