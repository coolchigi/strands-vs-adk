# Modeling Data Shapes with Interfaces and Types

## Outcomes

- Model entity shapes using interfaces and type aliases with readonly and optional modifiers
- Compose complex models via interface inheritance and type intersections
- Handle dynamic dictionaries with index signatures while addressing excess property checks

## Lessons

- [Interfaces, Type Aliases, and Property Modifiers](u2-l1-interfaces-type-aliases-and-property-modifiers/README.md)
- [Composing Shapes with Inheritance and Intersections](u2-l2-composing-shapes-with-inheritance-and-intersecti/README.md)
- [Index Signatures and Excess Property Checks](u2-l3-index-signatures-and-excess-property-checks/README.md)

## Project

Build an in-memory data schema for a blogging web application containing User, Post, Category, and Tag models using interface extension, intersection types for audit timestamps, and an index-signature-backed configuration map with immutable identifier properties.
