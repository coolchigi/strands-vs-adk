# Strict Compiler Configuration and Compilation

## Outcomes

- Compile TypeScript files using tsc and suppress emission on type errors
- Configure tsconfig.json with strict checks and target ECMAScript versions

## Lessons

- [Compiler CLI and Strict Type Validation](u1-l1-compiler-cli-and-strict-type-validation/README.md)
- [Configuring tsconfig.json and Target Downleveling](u1-l2-configuring-tsconfig-json-and-target-downlevelin/README.md)

## Project

Create a baseline project repository containing tsconfig.json configured with strict mode, noEmitOnError, and downleveling target, verifying that tsc without arguments successfully compiles valid files and prevents emit when intentional type errors are introduced.
